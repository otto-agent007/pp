# Pest Patrol Assets

Shared visual assets for Pest Patrol OS. Keep assets optimized, named in
lowercase kebab-case, and grouped by the surface that owns the visual meaning.

## Buckets

- `brand/` - logos, wordmarks, and brand marks.
- `icons/` - durable product icons that are not already covered by the app icon library.
- `status/` - reusable state symbols for operational status, sync, warnings, and success.
- `map/` - provider-free map, route, stop, and location assets.
- `empty-states/` - small illustrations or symbols for empty and blocked states.

Prefer SVG for logos and simple reusable marks. Raster assets should be added
only when they improve comprehension and should follow `docs/ASSET_PIPELINE.md`.
